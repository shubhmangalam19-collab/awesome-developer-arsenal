# Contributing to Awesome Developer Arsenal ⚡

Thank you for your interest in contributing! This project thrives on curated, high-quality resources that genuinely help developers build without unnecessary friction or cost.

---

## 🌟 Inclusion Guidelines

Before proposing a new item, ensure it meets our quality bar:

1. **Truly Generous Free Tier or 100% Free / Open-Source**:
   - Must have a genuinely usable perpetual free tier or open-source community edition.
   - No "14-day free trials" that require credit cards upfront.
2. **Production-Ready & Stable**:
   - Maintained actively (recent commits within the last 6 months).
   - High reliability and clean documentation.
3. **No Redundancy**:
   - We prefer quality over quantity. If suggesting an alternative to an existing tool, briefly explain why it belongs.

---

## 📝 How to Submit a Pull Request

1. **Fork** the repository.
2. **Create a branch** for your addition:
   ```bash
   git checkout -b add/tool-name
   ```
3. Add your tool to the appropriate category in [`README.md`](README.md):
   - Keep markdown tables sorted and consistently formatted.
   - Use direct, official URLs (no affiliate or referral links).
   - Keep descriptions concise, objective, and accurate.
4. **Commit** with a clean commit message following Conventional Commits:
   ```bash
   git commit -m "feat(resources): add ToolName to Free Hosting"
   ```
5. **Open a Pull Request** against `main` with a brief summary of the added resource.
